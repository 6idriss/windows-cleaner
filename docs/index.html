Install

Two ways. Both add a Clean Temp shortcut with the 007 icon to your Desktop and Start Menu.

Option 1 · one-line install

Open PowerShell and paste:

irm https://raw.githubusercontent.com/6idriss/windows-cleaner/main/install.ps1 | iex

Press Enter. Done.

Option 2 · download the zip

1Download CleanTemp.zip.
2Right-click it and choose Extract All.
3Double-click Install.bat, or Run CleanTemp.bat to run it once without installing.
If Windows SmartScreen warns you, click More info, then Run anyway. This happens because the files are not code-signed. The code is open, so you can read every line on GitHub first.

FAQ

Stuck? It's probably here.

Is it really free?

Yes. No paywall, no ads, no sign-up. The code is MIT licensed on GitHub.

Windows says "Windows protected your PC". Is it a virus?

No. SmartScreen warns about any app that isn't code-signed. Click More info, then Run anyway. Clean Temp is a single PowerShell script you can read on GitHub before running.

Why does it ask for administrator rights?

Windows temp, Prefetch and Windows Update folders can only be cleaned as admin. It doesn't change any system settings.

Can I get deleted files back?

No. Cleaned files skip the Recycle Bin. That's why Clean Temp only deletes junk and shows you everything before you press CLEAN.

My games or apps open slower after cleaning.

Normal, and only once. Shader and app caches rebuild the first time you open them again.

Some items said "nothing to clean" or didn't free everything.

Files that are in use are skipped. Close your browsers, Discord and Spotify, then clean again for a full clean.

Does Clean Temp send any data?

Only an anonymous usage count, at most once a day, so 007 can see how many people use it. It sends exactly three things:

  • a random install ID (made on your PC, not linked to you)
  • the app version, like 2.2.0
  • whether it opened normally or ran as the weekly auto-clean

No name, no files, no list of what you cleaned, nothing about your PC. To turn it off, untick Send an anonymous daily usage count at the bottom of the app.

How do I uninstall it?

Double-click Uninstall.bat from the zip, or run powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\CleanTemp\install.ps1" -Uninstall. This also removes the weekly task.
